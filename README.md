# Crimson Skies Patcher (Rust)

A command-line patcher for the **Windows PC release of Microsoft Crimson Skies (2000)**. It changes resolution and widescreen field of view (FOV), can apply a narrowly verified Wine/Proton crash workaround, and preserves the original game files before writing changes.

## Compatibility

**CrimsonSkiesFix supports Crimson Skies version 1.02 only.** Earlier versions are not supported.

If your game is not already updated to **v1.02**, install the official [Crimson Skies 1.02 update](https://www.moddb.com/games/crimson-skies/downloads/crimson-skies-update-v102) before using CrimsonSkiesFix. The linked download is an archived copy of the official update; check that the patch is applicable to your language/edition.
